# 极速分账 · SplitSnap

聚餐 / 旅行 AA 账单计算器 H5：瑞士国际主义 × 热敏纸出纸美学，零注册、零后端数据库、最少转账次数结算、扫码分享、热敏小票长图导出与官方宣传二维码海报。

- 公网访问：https://vuxiao.github.io/splitsnap/
- 产品介绍二维码海报：`product-intro-qr.png`（1080×1920 高清竖版）

## 核心能力

- **瑞士小票产品介绍页（Swiss Receipt Intro Cover）**：普通根地址访问默认呈现热敏机出纸式产品说明书，直观演示「7 笔乱账 ➔ 2 笔结清」算法价值；带 `#s=` / `?s=` 分享参数时直接跳过介绍页直达账单。
- **极速建账与瑞士印刷体徽章**：一键创建账本与参与人（自动分配 8 款纯矢量瑞士印刷体印章徽章，点击可切换样式），内置示例账单开箱即体验。
- **灵活消费录入**：支持均摊（轻松排除不喝酒/晚到成员）与自定义金额（实时总额差额校验），内置快捷数字键盘与 `+` 加法合算。
- **最小转账路径结算 + 群收款纯文本**：内部采用整数「分」运算 + 0.01 元余数确定性轮转 + 精确抵消优先的最小现金流算法，支持勾选「已结清」与一键复制群收款文字明细。
- **无后端 URL 状态同步**：通过短键紧凑序列化 + LZ-String 压缩至 URL Hash，微信扫码或点击链接即可 100% 还原账单并一键存副本到本地。
- **热敏小票结算长图 & 官方介绍海报**：Canvas 2D 绘制锯齿边电子结算小票与 `1080×1920` 官方产品介绍二维码海报，支持一键下载保存发群。
