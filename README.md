# 极速分账 · SplitSnap

聚餐 / 旅行 AA 账单计算器 H5：零注册、零后端数据库、最少转账次数结算、扫码分享与热敏纸小票长图导出。

## 核心能力

- **极速建账与成员管理**：一键创建账本与参与人（自动分配可爱头像/色块），内置示例账单开箱即体验。
- **灵活消费录入**：支持均摊（轻松排除不喝酒/晚到成员）与自定义金额（实时总额差额校验），内置快捷数字键盘与 `+` 加法合算。
- **最小转账路径结算**：内部采用整数「分」运算 + 0.01 元余数确定性轮转 + 精确抵消优先的最小现金流算法，将复杂多角债压缩至最少转账笔数，并支持勾选“已结清”。
- **无后端 URL 状态同步**：通过短键紧凑序列化 + LZ-String 压缩至 URL Hash，微信扫码或点击链接即可 100% 还原账单并一键存副本到本地。
- **热敏小票结算长图**：Canvas 2D 绘制带锯齿撕裂边缘的真实热敏纸结算小票（含明细、净额、最优转账、已结清印章与专属二维码），一键保存发群。
